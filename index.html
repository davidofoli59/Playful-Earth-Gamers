Staking Options

1 Win Match: Player wins the overall tournament/challenge.
2 Over/Under: Total squad score, kills, or circuit points.
3 First to X: First player to reach elimination threshold.
4 Combo Bet: Combine multiple options for compounded odds.

Odds Slip Guide

1. Select Challenge: Choose from verified esports lobbies.

2. Pick Options: Win match + Over 5.5 kills.

3. Set Stake: Enter PEG tokens or equivalent escrow.

Database & API Security

The browser requests. The backend verifies. Firebase authenticates. Paystack processes payment. The backend verifies Paystack. Firestore stores the authoritative state.

1. ABAC Firestore Rules

Users cannot change privileged fields (paymentStatus, role, accountStatus, membershipStatus) from the client. Deployed rules deny unauthorized writes mathematically.

2. Server-Authoritative Paystack

Secrets are stored server-side only. Callbacks are treated as untrusted until the backend performs a direct verification call with Paystack's live API.

3. Immutable Audit Trail

Registrations, logins, payment initializations, and authorization checks are recorded in the security audit stream with actor UIDs and timestamps.
